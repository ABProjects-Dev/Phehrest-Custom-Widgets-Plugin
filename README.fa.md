# ابزارک‌های اختصاصی فهرست

افزونه‌ای مستقل برای ابزارک‌های المنتور؛ نسخه فعلی افزونه `0.2.0` است. وضعیت ویجت همچنان **آزمایشی** است؛ پیش از استفاده در سایت عملیاتی آن را در محیط آزمایشی فروشگاه بررسی کنید.

## نصب آزمایشی

روی سایت آزمایشی WooCommerce و Elementor را نصب و فعال کنید، سپس این افزونه را فعال کنید. از منوی «ابزارک‌های فهرست»، ویجت را فعال و ذخیره کنید؛ ویجت‌ها به‌صورت پیش‌فرض غیرفعال‌اند. محصول جاری یا محصول مشخص را در تنظیمات ویجت انتخاب کنید. بخش «طراحی مشترک» برای پیش‌فرض‌های اختصاصی افزونه است؛ کنترل‌های Elementor می‌توانند آن‌ها را برای همان ویجت تغییر دهند.

حداقل نسخه‌ها: PHP 8.0، WordPress 6.4، Elementor 3.18 و WooCommerce 8.5. ترکیب حداقل و نسخه‌های جاری در CI آزموده می‌شوند، ولی Elementor Pro و همه قالب‌ها و افزونه‌های شخص ثالث جزو این تضمین نیستند.

ویجت‌ها با manifest کشف می‌شوند و منابعشان وابستگی خود ویجت در المنتور است. هنگام حذف فقط گزینه‌های اختصاصی فعال‌سازی، طراحی و دفترچه درخواست پاک می‌شوند؛ محصول، سفارش، تنظیمات فروشگاه و فایل‌های خارج از افزونه حذف نمی‌شوند. پاک‌سازی شبکه‌ای multisite هنوز پیاده‌سازی نشده است.

[راهنمای ویجت، الزامات هم‌زمانی و محدودیت‌ها](widgets/ajax-smart-add-to-cart/README.fa.md) و [دستورات آزمون](README.md) را ببینید. تصاویر واقعی آزمون مرورگر در artifact اجرای GitHub Actions قرار می‌گیرند؛ تصویر خطای شبکه عمداً با قطع اتصال ایجاد می‌شود.
