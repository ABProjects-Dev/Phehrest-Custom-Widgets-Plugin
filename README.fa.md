# ابزارک‌های اختصاصی فهرست

افزونه‌ای مستقل برای ابزارک‌های المنتور؛ وضعیت فعلی **آزمایشی و نامناسب برای سایت عملیاتی** است. شماره `0.1.0-dev` فقط شناسه توسعه است و انتشار یا تأیید سازگاری محسوب نمی‌شود.

## نصب آزمایشی

روی سایت آزمایشی، WooCommerce و Elementor را نصب و فعال کنید، سپس این افزونه را فعال کنید. از منوی «ابزارک‌های فهرست»، ابزارک موردنظر را فعال و ذخیره کنید؛ ابزارک‌ها به‌صورت پیش‌فرض غیرفعال‌اند. ابزارک را در قالب محصول قرار دهید یا شناسه عددی محصول را در تنظیمات وارد کنید.

حداقل نسخه‌های اولیه: PHP 8.0، WordPress 6.4، Elementor 3.18 و WooCommerce 8.5. این اعداد هنوز ماتریس سازگاری آزموده‌شده نیستند.

## معماری و حذف

ویجت‌ها با manifest و کلاس ماژول کشف می‌شوند و منابعشان وابستگی خود ویجت در المنتور است. تنظیم فعال‌سازی در گزینه اختصاصی `pcw_enabled_widgets` نگهداری و هنگام حذف افزونه پاک می‌شود. داده محصول، سفارش و تنظیمات فروشگاه دست‌کاری یا حذف نمی‌شوند. در multisite پاک‌سازی شبکه‌ای تنظیمات هنوز پیاده‌سازی نشده است.

برای نحوه کار، محدودیت و آزمون‌ها، [راهنمای ویجت](widgets/ajax-smart-add-to-cart/README.fa.md) را ببینید. دستورات آزمون در [راهنمای انگلیسی](README.md) آمده‌اند.
